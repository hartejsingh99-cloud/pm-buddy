# Manager Notes

Append-only log of manager's suggestions, feedback, directional asks.
Use `/pm-buddy manager "<what they said> — <context>"`.

Format:
```
## YYYY-MM-DD
- **Direction / feedback / ask**
- **Context:** where it came from (1:1, standup, Slack, review)
- **My read:** one-line interpretation (what I think they actually want)
- **Follow-up:** action or "none yet"
```
